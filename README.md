# Systems_Monitoring_and_telemetry

This repository contains code and documentation related to systems monitoring and  telemetry. This repository is intended to be a ClI tool + web dashboard for monitoring and telemetry purposes, that works on cross platform. 

The project consists of a monitoring agent that collects system metrics, a FastAPI backend that receives and stores telemetry, and a web dashboard for viewing system information.

## Current Architecture


# Tech stack:
  Python,FastAPI, SQLite simple html/js dashboard.
